# 产品资料 → AI 知识库语料生成器

**一句话**：把一张字段混乱的产品信息 Excel，自动整理成结构化 Markdown 语料库，
可直接作为 AI 知识库（RAG）的语料使用 —— 原本人工整理的工作，变成运行一次脚本。

> ⚠️ 本仓库 `data/` 下全部为**自造的虚构示例数据**（品牌「声屿」为虚构），
> 不含任何真实公司或客户信息。

---

## 一、它解决什么问题

售前客服需要快速查询各型号产品的参数与卖点，但这些信息通常是：

- **分散**在多张表里（产品信息表 / 卖点表 / 参数表）
- **字段口径不统一**，且存在大量空值
- 人工翻阅**耗时**，而且容易漏

---

## 二、功能

| # | 功能 | 说明 |
|---|---|---|
| 1 | **字段统一** | 把不同来源的产品表合并成一张、统一列名口径 |
| 2 | **自动清洗** | 跳过表头行、剔除全空行、空值统一填「无」（避免 `nan` 混进知识库） |
| 3 | **卖点拆分** | 按分隔符把长段卖点拆成条目，**且不会切坏括号内的内容** |
| 4 | **核心词归组** | 提取每条卖点的核心关键词，把「同一功能的不同表述」归到一组 |
| 5 | **结构化输出** | 输出 Markdown，`#` / `##` 标题层级天然对应知识库的**切块边界** |

---

## 三、技术

`Python` · `pandas` · `re`（正则）· `collections.defaultdict` · `Markdown`

---

## 四、怎么运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 生成示例数据（12 个虚构产品）→ data/sample_products.xlsx
python make_sample_data.py

# 3. 生成语料库 → output/product_corpus.md
python build_corpus.py
```

运行后控制台会打印：

```
读取到的数据形状：12 行 × 21 列
有效产品数：12

语料库已生成：.../output/product_corpus.md
  产品数：12
  卖点类别数：31
```

## 七、开发中踩过的坑（记下来，避免再犯）

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 1 | 读到的列名不对 | 源表**第 1 行是标题行**，真正的列名在第 2 行 | 读取时加 `header=1` |
| 2 | 卖点被切成两半，出现「游戏可用）」这种半截条目 | **括号里的逗号**被当成了分隔符 | 改成「括号感知」的拆分：逐字符遍历，只有不在括号里时逗号才作分隔符 |
| 3 | 数字输出成 `1200.0` / `8.0小时` | 该列**只要有一个空值**，pandas 就会把整列当成小数 | 输出前判断结尾是不是 `.0`，是就切掉 |
